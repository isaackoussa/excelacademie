Versions

Module 1 · 90 min

Des données que le dashboard peut digérer

80 % des dashboards ratés se jouent ici. Un tableau croisé dynamique ne rattrape jamais une base mal structurée — il la recopie en plus joli.

1.1

Une ligne = un fait, une colonne = une variable

Le format que les humains lisent bien (mois en colonnes) est exactement celui qu'Excel exploite mal. Il faut une base « à plat » : chaque ligne raconte un événement complet.

1.2

Le tableau structuré, votre meilleur allié

Sélectionnez une cellule de votre base, faites Ctrl+L (Ctrl T en anglais), puis renommez-le immédiatement dans Création de tableau → Nom du tableau. Ce nom devient une adresse vivante.

Piège

Un tableau structuré n'accepte pas les cellules fusionnées, les lignes vides au milieu, ni deux en-têtes identiques. Excel renomme silencieusement en Produit2 — et votre formule pointe alors sur la mauvaise colonne.

1.3

Nettoyer avec Power Query

Power Query (Données → Obtenir des données) enregistre vos manipulations comme une recette. Le mois prochain, nouveau fichier, même recette, un clic sur Actualiser tout.

Les six transformations qui servent tout le temps

  • Type de données — forcez Date, Nombre décimal, Texte dès la deuxième étape. 90 % des bugs de TCD viennent d'une date restée en texte.
  • Dépivoter les colonnes — transforme un rapport en base (figure 3).
  • Fractionner une colonne — par délimiteur, par nombre de caractères.
  • Colonne à partir d'exemples — vous tapez deux résultats attendus, Power Query devine la règle.
  • Fusionner des requêtes — l'équivalent d'un RECHERCHEX, mais côté données, une fois pour toutes.
  • Ajouter des requêtes — empile 12 fichiers mensuels en une seule table.

Astuce : charger depuis un dossier

Données → Obtenir des données → À partir d'un fichier → À partir d'un dossier. Chaque nouveau CSV déposé dans le dossier est absorbé au prochain Actualiser tout. C'est le dispositif le plus rentable de toute la formation.

1.4

Les cinq saletés à traquer

Cellules fusionnées

Elles cassent le tri, le filtre, le TCD. Remplacez par Centrer sur plusieurs colonnes dans Ctrl 1 → Alignement.

Totaux au milieu de la base

Un TCD les comptera comme des lignes. Les totaux se calculent, ils ne se stockent pas.

Nombres stockés en texte

Alignés à gauche, ignorés par SOMME. Correction rapide : coller-spécial Ajouter une cellule vide, ou Convertir dans Power Query.

Espaces invisibles

« Ouest » ≠ « Ouest ». =SUPPRESPACE(A2), ou Format → Supprimer les espaces dans Power Query.

Dates en texte

Test imparable : =ESTNUM(A2). Si c'est FAUX, aucun groupement par mois ne fonctionnera jamais.

Lignes en double

Données → Supprimer les doublons — mais toujours sur une copie, et seulement après avoir vérifié quelles colonnes définissent l'unicité.

Module 2 · 100 min

Les huit formules qui portent un dashboard

On n'a pas besoin de connaître 400 fonctions. Il en faut huit, bien comprises, et surtout savoir laquelle recalcule et laquelle ralentit tout.

2.1

RECHERCHEX : la fin de RECHERCHEV

// dans la table Ventes, ramener la gamme du produit =RECHERCHEX([@Code] ; Produits[Code] ; Produits[Gamme] ; "Inconnu") // avant 2021, l'équivalent robuste =INDEX(Produits[Gamme] ; EQUIV([@Code] ; Produits[Code] ; 0))

Piège

Le 4e argument est facultatif — mais si vous l'omettez, une correspondance manquante renvoie #N/A, et un seul #N/A contamine toute la colonne de votre TCD. Mettez toujours une valeur de repli explicite : "Inconnu" ou 0, jamais "" dans une colonne numérique.

2.2

SOMME.SI.ENS : agréger sous conditions

=SOMME.SI.ENS(Ventes[CA] ; Ventes[Région] ; $B$2 ; Ventes[Gamme] ; $B$3) // avec une fourchette de dates — noter les guillemets autour de l'opérateur =SOMME.SI.ENS(Ventes[CA] ; Ventes[Date] ; ">="&$D$2 ; Ventes[Date] ; "<="&$D$3) // la même famille : NB.SI.ENS, MOYENNE.SI.ENS, MAX.SI.ENS, MIN.SI.ENS =NB.SI.ENS(Ventes[Client] ; "<>")
2.3

Les formules dynamiques : une formule, plusieurs cellules

Depuis Excel 2021, une formule peut renvoyer un bloc entier de résultats, qui se « déverse » dans les cellules voisines. C'est ce qui permet des listes de filtres ou des tops qui grandissent tout seuls.

=UNIQUE(Ventes[Région]) // la liste des valeurs distinctes =TRIER(UNIQUE(Ventes[Région])) // …triée =FILTRE(Ventes ; Ventes[Région]=$B$1 ; "aucune vente") // un sous-tableau vivant =TRIER(FILTRE(Ventes ; Ventes[CA]>5000) ; 5 ; -1) // trié par la 5e colonne, décroissant =PRENDRE(TRIER(Récap ; 2 ; -1) ; 5) // le top 5

LET : nommer pour ne plus se répéter

Quand la même sous-expression revient trois fois dans une formule, elle est calculée trois fois. LET la nomme et la calcule une seule fois — plus rapide, et surtout relisible dans six mois.

=LET( ca ; SOMME.SI.ENS(Ventes[CA] ; Ventes[Région] ; $B$1) ; obj ; RECHERCHEX($B$1 ; Objectifs[Région] ; Objectifs[Cible] ; 0) ; SI(obj=0 ; "pas d'objectif" ; ca/obj - 1) )

Module 3 · 110 min

Le tableau croisé dynamique, moteur du dashboard

Le TCD n'est pas un objet de présentation. C'est le calculateur qu'on cache dans une feuille technique, et dont on ne montre que les graphiques.

3.1

Quatre zones, et c'est tout

  1. Cliquez dans le tableau Ventes → Insertion → Tableau croisé dynamique.
  2. Cochez Ajouter ces données au modèle de données. C'est ce qui débloque les relations et les mesures.
  3. Placez-le sur une feuille dédiée, nommée TCD, que vous masquerez à la fin.
  4. Renommez chaque champ de valeur : « Somme de CA » devient CA — les graphiques hériteront de ce nom.
  5. Clic droit → Options du TCD → Disposition : décochez Ajuster la largeur des colonnes lors de la mise à jour, sinon votre mise en page saute à chaque actualisation.
3.2

Le modèle en étoile

Une table de faits au centre, des tables de dimensions autour, reliées par une clé. Ce schéma vaut pour Excel comme pour Power BI, et il évite l'immense majorité des RECHERCHEX en cascade.

Pourquoi une table Calendrier séparée

Le regroupement automatique par mois d'Excel se casse dès qu'il manque des jours, et ne sait pas gérer un exercice décalé ni les jours ouvrés. Une table de dates complète, une ligne par jour, résout tout cela définitivement — et c'est elle qui alimente la chronologie du module 5.

3.3

Mesures : les calculs qui suivent le filtre

Une mesure (Power Pivot) se recalcule dans le contexte de chaque cellule du TCD. C'est ce qui permet d'écrire « % de croissance » une seule fois, et de le voir juste par région, par mois, par gamme, et au total.

// Données → Mesures → Nouvelle mesure. Syntaxe DAX, virgule comme séparateur. CA := SUM(Ventes[CA]) Commandes := DISTINCTCOUNT(Ventes[N° commande]) CA N-1 := CALCULATE([CA], SAMEPERIODLASTYEAR(Calendrier[Date])) Croissance % := DIVIDE([CA] - [CA N-1], [CA N-1]) Marge % := DIVIDE([CA] - SUMX(Ventes, Ventes[Qté] * RELATED(Produits[Coût])), [CA])

Mesure

Calculée au moment de l'affichage, dans le contexte du filtre. Ne pèse rien en mémoire. À privilégier pour tout ce qui s'agrège.

recommandé

Colonne calculée

Calculée ligne par ligne, stockée. Nécessaire seulement quand la valeur doit servir de catégorie (ligne, colonne ou segment).

au cas par cas

Piège : DIVIDE plutôt que /

[CA]/[CA N-1] renvoie une erreur sur la première année, où N-1 vaut zéro — et l'erreur se propage jusqu'au total. DIVIDE() renvoie un blanc propre à la place.

Piège : LIREDONNEESTABCROISDYNAMIQUE

Pointer une cellule de TCD depuis une formule génère automatiquement LIREDONNEESTABCROISDYNAMIQUE(...) (GETPIVOTDATA), qui casse dès que le TCD change de forme. Pour le désactiver : Analyse du TCD → flèche à côté de « Options » → décocher Générer GETPIVOTDATA.

4.2

Le dépouillement

Un graphique Excel par défaut contient une demi-douzaine d'éléments qui ne portent aucune information. Les retirer double la lisibilité, sans rien ajouter.

Checklist de dépouillement

  • Supprimer le quadrillage (clic sur une ligne → Suppr) ou le passer en très clair.
  • Supprimer la légende dès qu'il n'y a qu'une série.
  • Remplacer l'axe des valeurs par des étiquettes de données directes (clic droit → Ajouter des étiquettes).
  • Trier les catégories par valeur décroissante — dans le TCD source, pas à la main.
  • Griser tout sauf la barre dont on parle : clic, puis second clic sur une seule barre pour la sélectionner isolément.
  • Réduire les intervalles entre barres à 40–60 % (clic droit → Mettre en forme la série → Largeur de l'intervalle).

Piège : les couleurs qui changent toutes seules

Un graphique croisé dynamique réattribue ses couleurs quand un filtre fait disparaître une catégorie. « Pro » était vert, il devient bleu. Fixez chaque série manuellement, ou construisez le graphique sur une plage de résultats stable plutôt que directement sur le TCD.

Module 5 · 80 min

Un tableau de bord qu'on pilote au doigt

C'est ce qui sépare un rapport d'un outil : le lecteur pose ses propres questions sans vous appeler.

5.1

Segments et chronologies

Un segment est un filtre visuel branché sur un ou plusieurs TCD. La fonction décisive s'appelle Connexions de rapport : c'est elle qui fait qu'un seul clic repilote tout le dashboard.

  1. Cliquez dans un TCD → Analyse du TCD → Insérer un segment, cochez Région et Gamme.
  2. Clic droit sur le segment → Connexions de rapport → cochez tous les TCD du classeur.
  3. Pour les dates, préférez Insérer une chronologie : elle propose années / trimestres / mois / jours avec un curseur de plage.
  4. Mettez en forme : Options de segment → Colonnes pour passer en horizontal, et un style qui reprend votre accent.
  5. Clic droit → Taille et propriétés → décochez Déplacer et dimensionner avec les cellules, sinon un masquage de colonne écrase vos segments.
5.2

Quand le segment ne suffit pas

Liste déroulante dynamique

Données → Validation des données → Liste, et comme source =$D$1# pointant vers un UNIQUE. La liste grandit avec les données, sans maintenance.

Cases à cocher

Excel 365 : Insertion → Case à cocher — la cellule vaut VRAI/FAUX, directement exploitable dans un SI ou un FILTRE.

Boutons d'options

Développeur → Insérer → Bouton d'option. Trois boutons liés à une même cellule renvoient 1, 2 ou 3 : parfait pour basculer entre CA / Volume / Marge.

Navigation par formes

Une forme + Ctrl K → Emplacement dans ce document. C'est ainsi qu'on fabrique un menu latéral entre plusieurs pages du dashboard.

// bascule d'indicateur pilotée par un bouton d'option en $B$5 =CHOISIR($B$5 ; [CA] ; [Volume] ; [Marge]) // tableau de détail qui suit la liste déroulante en $B$1 =FILTRE(Ventes ; (Ventes[Région]=$B$1) * (Ventes[CA]>$B$2) ; "aucun résultat") // le * joue le rôle du ET, le + celui du OU

Astuce : le titre qui parle

Faites réagir le titre du dashboard au filtre : ="CA "&$B$1&" — "&TEXTE($D$2;"mmmm aaaa"), puis sélectionnez la zone de texte d'un graphique, tapez = et cliquez sur cette cellule. Le titre devient vivant.

Module 6 · 90 min

Composer la page, guider l'œil

À ce stade tout fonctionne. Il reste à faire en sorte qu'on comprenne en huit secondes — durée réelle d'attention d'un lecteur de dashboard.

6.1

Une grille, pas un collage

Le secret d'un dashboard Excel qui ne ressemble pas à du bricolage tient en une manipulation : réduire la largeur de toutes les colonnes à 2 pixels, et composer par fusion de blocs. Vous obtenez une grille de mise en page, comme en PAO.

Le ménage indispensable, feuille Dashboard

  • Affichage → décocher Quadrillage, En-têtes, Barre de formule.
  • Un fond uni sur toute la feuille : Ctrl A puis une couleur de remplissage très claire, et des blocs en blanc par-dessus. La hiérarchie apparaît toute seule.
  • Affichage → Figer les volets sur la ligne sous le titre, pour que les filtres restent visibles.
  • Révision → Protéger la feuille en autorisant uniquement les segments et les listes déroulantes.
6.2

La mise en forme conditionnelle, avec parcimonie

Piège : les règles qui se multiplient

Copier-coller des cellules duplique les règles, et le Gestionnaire des règles finit avec 200 entrées quasi identiques — le classeur rame. Vérifiez-le régulièrement dans Accueil → Mise en forme conditionnelle → Gérer les règles → Cette feuille, et appliquez plutôt une règle unique sur une grande plage.

6.3

La couleur : une seule décision

Un accent

Une seule couleur saturée, celle de la marque. Elle sert à désigner ce qu'il faut regarder — donc jamais plus de 10 % de la surface.

désigner

Des neutres

Trois gris suffisent : fond, bloc, texte secondaire. Tout ce qui n'est pas le sujet du moment est gris.

structurer

Deux sémantiques

Un vert et un rouge, uniquement pour bon / mauvais. Ils ne servent à rien d'autre, jamais comme couleurs de série.

alerter

Accessibilité

8 % des hommes distinguent mal le rouge du vert. Doublez toujours le signal : une flèche, un signe, un mot. Un chiffre en rouge sans − devant n'est pas lu comme une baisse par tout le monde.

Formats de nombres personnalisés

Ctrl 1 → Personnalisé. Ces codes changent l'affichage sans toucher à la valeur :

# ##0 " €" // 1 240 € # ##0,0 " k€";-# ##0,0 " k€";"—" // positif ; négatif ; zéro affiché en tiret 0,0 %;[Rouge]-0,0 % // le négatif en rouge automatiquement [>=1000000]0,00 " M€";# ##0 " €" // change d'unité selon la grandeur ▲ 0,0 %;▼ 0,0 %;– // la flèche fait partie du format

Module 7 · 70 min

Automatiser, protéger, livrer

Le vrai test d'un dashboard : que quelqu'un d'autre l'ouvre dans six mois, clique une fois, et obtienne des chiffres à jour sans vous appeler.

7.1

La chaîne d'actualisation

7.2

Un bouton Actualiser

Trois lignes de VBA valent mieux qu'une consigne écrite dans un coin. Enregistrez le classeur en .xlsm, ouvrez l'éditeur avec Alt F11, insérez un module :

Sub ActualiserTout() ' évite le clignotement pendant l'opération Application.ScreenUpdating = False ThisWorkbook.RefreshAll Application.CalculateUntilAsyncQueriesDone Range("Dashboard!C2").Value = "Données au " & Format(Now, "dd/mm/yyyy hh:nn") Application.ScreenUpdating = True MsgBox "Dashboard à jour.", vbInformation End Sub

Puis dessinez une forme sur le dashboard, clic droit → Affecter une macro → ActualiserTout. C'est souvent la seule ligne de code de tout le projet, et elle évite dix questions par mois.

Sans macro

Si la politique de sécurité interdit les .xlsm : gardez le classeur en .xlsx avec l'actualisation à l'ouverture, et affichez la fraîcheur des données par formule dans Power Query (une colonne DateTime.LocalNow() ajoutée à une requête dédiée d'une seule ligne).

7.3

Checklist de livraison

Alléger

Requêtes intermédiaires en Connexion seule. Supprimer les feuilles de travail mortes. Ctrl Fin doit s'arrêter à la dernière vraie cellule — sinon supprimez les lignes fantômes et enregistrez.

Protéger

Révision → Protéger la feuille, cocher uniquement « Utiliser les segments » et « Utiliser les tableaux croisés dynamiques ». Masquer les feuilles TCD et CALCULS (clic droit sur l'onglet → Masquer).

Documenter

Une feuille LISEZ-MOI : d'où viennent les données, à quelle fréquence, qui contacter, quelles sont les règles de calcul discutables. Trois paragraphes suffisent.

Distribuer

OneDrive / SharePoint plutôt qu'une pièce jointe : un seul fichier, une seule version. Excel Online affiche segments et TCD, mais n'actualise pas Power Query — prévoyez une actualisation planifiée ou un poste de référence.

Le test des six mois

Ouvrez votre classeur sur une autre machine, avec un compte qui n'est pas le vôtre. Les chemins de fichiers absolus (C:\Users\...) cassent immédiatement. Utilisez un chemin réseau ou paramétrez le dossier source dans une requête de paramètre unique.

Projet fil rouge · 2 à 3 h

Le dashboard commercial, de zéro à livrable

Douze étapes qui rejouent les sept modules dans l'ordre. À la fin, un fichier que vous pouvez montrer.

Pas à pas

Les douze étapes

  1. Structurer le classeur. Cinq feuilles : LISEZ-MOI, SOURCE, TCD, CALCULS, DASHBOARD. Les trois du milieu finiront masquées.
  2. Importer. Power Query sur le dossier des exports. Types forcés, erreurs supprimées, colonnes inutiles retirées.
  3. Construire le calendrier. Une ligne par jour sur trois ans, avec Année, Trimestre, Mois, N° semaine.

Un classeur rapide, et des chiffres qu'on peut défendre

Deux compétences que personne n'enseigne et que tout le monde finit par réclamer : faire qu'un classeur cesse de ramer, et pouvoir prouver qu'un chiffre est juste.

9.1

Où part le temps de recalcul

Le mode de calcul manuel

Formules → Options de calcul → Manuel gèle le recalcul ; F9 le déclenche quand vous le décidez. Indispensable au-dessus de quelques centaines de milliers de formules — mais le réglage est enregistré dans le fichier et suit le classeur chez le destinataire. 9.2

Auditer une formule qu'on n'a pas écrite

  • Repérer les antécédents / dépendants (Formules → Audit de formules) : des flèches montrent d'où vient et où va la valeur. Ctrl [ et Ctrl ] font la même chose au clavier.
  • Évaluer la formule : déroule le calcul étape par étape. Plus lent que F9 sur une portion, mais il montre l'ordre d'évaluation.
  • Fenêtre espion : garde sous les yeux la valeur de cellules situées sur d'autres feuilles pendant que vous modifiez le modèle. C'est l'outil qui révèle les effets de bord.
  • Afficher les formules (Ctrl ") : une vue d'ensemble qui fait sauter aux yeux la cellule où quelqu'un a tapé un nombre en dur au milieu d'une colonne de formules.
  • Atteindre / Cellules → Différences entre lignes : sélectionne exactement les cellules qui ne suivent pas le motif de leurs voisines. Le détecteur d'anomalies gratuit.
9.3

Les cellules de contrôle

La pratique qui distingue un classeur professionnel : chaque étape porte un contrôle qui doit valoir zéro. Si un seul passe au rouge, le dashboard entier se signale comme non fiable.

Astuce

Comparez toujours la somme d'un montant, pas seulement un nombre de lignes. Une jointure qui duplique des lignes conserve parfois le bon compte après filtrage, mais double le CA — et ça ne se voit qu'au total.

Excel appliqué : finance, comptabilité, assurance

Les trois métiers partagent les mêmes exigences — le centime juste, la date exacte, le contrôle qui prouve. Ce module couvre ce qu'Excel sait faire nativement, sans une ligne de code.

10.1

Le socle commun : arrondis, signes, dates

Avant toute fonction métier, trois réglages. Ce sont eux qui décident si votre total tombe juste, et ils se trompent silencieusement.

Convention de signe

Fixez-la une fois et écrivez-la sur la feuille Hypothèses : débit positif / crédit négatif, ou deux colonnes séparées. Les deux se défendent, le mélange ne se défend pas.

Dates de fin de période

=FIN.MOIS(date;0) dernier jour du mois, =FIN.MOIS(date;-1)+1 premier jour. =MOIS.DECALER pour décaler une échéance sans casser les fins de mois.

Fraction d'année

=FRACTION.ANNEE(début;fin;base) — la fonction la plus utile des trois métiers. La base choisit la convention : 0 pour 30/360, 1 pour exact/exact, 3 pour exact/365.

Piège : la base de calcul des jours

30/360, exact/360, exact/365, exact/exact — ces conventions donnent des résultats différents sur les mêmes dates. Les intérêts obligataires, un prorata de prime et un calcul de pénalités de retard n'utilisent pas forcément la même. Notez la base retenue à côté du résultat, sinon personne ne pourra refaire le calcul.

10.2

Finance : flux, rentabilité, trésorerie

// Flux à dates réelles — presque toujours ce qu'il faut en pratique =VAN.PAIEMENTS(taux ; Flux[Montant] ; Flux[Date]) // XNPV =TRI.PAIEMENTS(Flux[Montant] ; Flux[Date]) // XIRR // Flux à périodes régulières — attention, VAN actualise dès la 1re période =VAN(taux ; B3:B14) + B2 // le flux initial B2 reste HORS de la fonction =TRI(B2:B14) // Emprunt : mensualité, et sa décomposition période par période =VPM(taux/12 ; durée*12 ; -capital) // PMT =INTPER(taux/12 ; n° ; durée*12 ; -capital) // part d'intérêts du mois n =PRINCPER(taux/12 ; n° ; durée*12 ; -capital) // part de capital du mois n // Retrouver une inconnue =TAUX(nb_périodes ; -mensualité ; capital) // taux effectif réel d'une offre =NPM(taux/12 ; -mensualité ; capital) // en combien de temps c'est remboursé

Piège : VAN n'est pas la VAN

La fonction VAN d'Excel actualise toutes les valeurs qu'on lui donne, y compris la première — alors que l'investissement initial, en date zéro, ne doit pas l'être. C'est l'erreur la plus fréquente de tous les modèles financiers sous Excel. Laissez le flux initial en dehors et additionnez-le, comme ci-dessus.

Trois indicateurs à savoir poser

Seuil de rentabilité = charges fixes / taux de marge sur coût variable. BFR = stocks + créances clients − dettes fournisseurs, qu'on exprime en jours de CA pour le comparer d'une année sur l'autre. Délai de règlement client (DSO) = créances / CA TTC × 365 : le premier chiffre à regarder quand la trésorerie se tend alors que le carnet est plein.

10.3

Comptabilité : de l'écriture aux états

Un export comptable — FEC, grand livre, balance — est déjà une base à plat : une ligne par écriture. C'est le cas le plus favorable pour Excel, à condition de ne jamais le retoucher à la main.

Lettrage et rapprochement bancaire

Rapprocher deux listes qui ne se ressemblent pas tout à fait. Clé de rapprochement composite : =[@Date]&"|"&ARRONDI([@Montant];2), puis NB.SI.ENS pour compter les correspondances et repérer les doublons avant de lettrer.

Amortissements

AMORLIN pour le linéaire, AMORDEGRC et AMORLINC pour les règles fiscales françaises avec prorata, DDB et VDB pour le dégressif. Un tableau d'amortissement se construit en lignes d'exercices, jamais en formules recopiées à la main.

TVA

Collectée moins déductible, par taux. Le contrôle : le total de la TVA collectée recalculée depuis les bases doit retomber sur le solde du compte 44571 à l'euro près. L'écart signale une facture saisie au mauvais taux.

Clôture

Cut-off (rattachement à l'exercice), charges à payer, produits constatés d'avance, provisions. Chacun mérite une ligne de contrôle propre — ce sont les postes que le commissaire aux comptes ouvrira en premier.

10.4

Assurance : le portefeuille et sa rentabilité

La difficulté propre à l'assurance tient en une phrase : la prime est encaissée d'avance, le sinistre arrive plus tard. Tous les indicateurs découlent de ce décalage.

// Prime acquise sur l'exercice, contrat par contrat =[@Prime] * FRACTION.ANNEE( MAX([@Début];Hyp_DebutEx) ; MIN([@Fin];Hyp_FinEx) ; 1 ) // Charge sinistres = payés + provisions de clôture − provisions d'ouverture =SOMME.SI.ENS(Sin[Payé];Sin[Exercice];A2) + SOMME.SI.ENS(Sin[PSAP_clôture];Sin[Exercice];A2) - SOMME.SI.ENS(Sin[PSAP_ouverture];Sin[Exercice];A2) // Les ratios S/P =SI(primes_acquises=0 ; "" ; charge_sinistres / primes_acquises) Ratio combiné =S/P + frais_généraux / primes_acquises Taux de rétention =NB.SI.ENS(Ctr[Statut];"Reconduit") / NB.SI.ENS(Ctr[Échéance];"<="&Hyp_FinEx) // Sinistre moyen et fréquence — les deux moteurs du S/P Fréquence =nb_sinistres / nb_contrats_moyens Coût moyen =charge_sinistres / nb_sinistres

Piège : la moyenne qui ment

Un S/P global stable peut cacher une fréquence qui monte et un coût moyen qui baisse — deux dynamiques opposées, deux décisions opposées. Affichez toujours les deux composantes à côté du ratio, et ne commentez jamais un S/P sans son volume de primes : un ratio calculé sur trois contrats ne veut rien dire.

La règle de performance : travailler en mémoire

Chaque lecture ou écriture dans une cellule traverse la frontière entre VBA et le moteur Excel. Sur 100 000 lignes, c'est 100 000 allers-retours. La solution tient en trois lignes : tout lire d'un coup, calculer dans un tableau, tout réécrire d'un coup.

' ✕ LENT — un aller-retour par cellule For k = 2 To 100000 Cells(k, 5).Value = Cells(k, 3).Value * Cells(k, 4).Value Next k ' ✓ RAPIDE — deux allers-retours en tout Dim src As Variant, res() As Double, k As Long src = Range("C2:D100001").Value ' 1 lecture : tableau 100000 x 2 ReDim res(1 To UBound(src, 1), 1 To 1) For k = 1 To UBound(src, 1) res(k, 1) = src(k, 1) * src(k, 2) ' calcul pur, en mémoire Next k Range("E2").Resize(UBound(res, 1), 1).Value = res ' 1 écriture

11.5

Assurance — triangle de liquidation et Chain-Ladder

Le calcul de provisionnement le plus répandu. On observe des sinistres payés cumulés par année de survenance et année de développement, on en déduit des facteurs de passage, et on prolonge jusqu'à l'ultime.

Option Explicit ' Facteurs de développement pondérés, sur un triangle cumulé carré. ' triangle : plage n x n, cellules non observées vides. Function FacteursChainLadder(triangle As Range) As Variant Dim t As Variant: t = triangle.Value Dim n As Long: n = UBound(t, 1) Dim f() As Double: ReDim f(1 To n - 1) Dim i As Long, j As Long, num As Double, den As Double For j = 1 To n - 1 num = 0: den = 0 ' seules les lignes observées en j ET en j+1 entrent au dénominateur For i = 1 To n - j den = den + t(i, j) num = num + t(i, j + 1) Next i If den <> 0 Then f(j) = num / den Else f(j) = 1 Next j FacteursChainLadder = f End Function ' Complète le triangle et renvoie ultime et provision par année de survenance. Sub ProjeterUltimes() Dim rg As Range: Set rg = ThisWorkbook.Names("Dat_Triangle").RefersToRange Dim t As Variant: t = rg.Value Dim n As Long: n = UBound(t, 1) Dim f As Variant: f = FacteursChainLadder(rg) Dim res() As Double: ReDim res(1 To n, 1 To 2) Dim i As Long, j As Long, dernier As Long, ult As Double For i = 1 To n dernier = n - i + 1 ' dernière colonne observée de la ligne i ult = t(i, dernier) For j = dernier To n - 1 ult = ult * f(j) Next j res(i, 1) = ult ' ultime res(i, 2) = ult - t(i, dernier) ' provision restant à payer Next i ThisWorkbook.Names("Res_Ultimes").RefersToRange.Resize(n, 2).Value = res End Sub

Piège

Le triangle doit être cumulé. Appliquer Chain-Ladder à des paiements non cumulés donne des facteurs qui n'ont aucun sens — et le résultat reste plausible à l'œil, ce qui le rend dangereux. Ajoutez un contrôle : chaque ligne doit être croissante.

11.6

Assurance — tarification vie sur table de mortalité

Une fonction personnalisée (UDF) utilisable directement dans une cellule : prime unique d'un capital décès temporaire, actualisée, à partir d'une table de survivants l(x).

' lxTable : une colonne de survivants, ligne 1 = âge 0, ligne 2 = âge 1, etc. ' x : âge à la souscription · n : durée en années · i : taux technique annuel Function PrimeUniqueDeces(lxTable As Range, x As Long, _ n As Long, capital As Double, i As Double) As Double Dim lx As Variant: lx = lxTable.Value Dim v As Double: v = 1 / (1 + i) ' facteur d'actualisation Dim k As Long, a As Double, lStart As Double lStart = lx(x + 1, 1) ' survivants à l'âge x If lStart <= 0 Then PrimeUniqueDeces = CVErr(xlErrValue): Exit Function For k = 0 To n - 1 ' décès entre x+k et x+k+1, actualisés en fin d'année a = a + v ^ (k + 1) * (lx(x + k + 1, 1) - lx(x + k + 2, 1)) / lStart Next k PrimeUniqueDeces = capital * a ' prime pure, hors chargements End Function

Dans la cellule

=PrimeUniqueDeces(Hyp_Lx ; 45 ; 10 ; 100000 ; 0,02) — la fonction se comporte comme n'importe quelle fonction Excel, et se recalcule avec les hypothèses.

Ce qu'il reste à ajouter

Chargements d'acquisition et de gestion, frais sur prime, éventuelle sélection médicale, périodicité de paiement. La prime pure n'est jamais la prime commerciale.

Sub GenererEcheancier() Dim capital As Double, tauxAnnuel As Double, nMois As Long With ThisWorkbook capital = .Names("Hyp_Capital").RefersToRange.Value tauxAnnuel = .Names("Hyp_Taux").RefersToRange.Value nMois = .Names("Hyp_DureeMois").RefersToRange.Value End With Dim i As Double: i = tauxAnnuel / 12 Dim mens As Double If i = 0 Then mens = capital / nMois Else mens = capital * i / (1 - (1 + i) ^ -nMois) ' annuité constante End If Dim res() As Double: ReDim res(1 To nMois, 1 To 5) Dim k As Long, crd As Double, interets As Double, amort As Double crd = capital For k = 1 To nMois interets = crd * i amort = mens - interets res(k, 1) = k res(k, 2) = crd ' capital restant dû en début de période res(k, 3) = interets res(k, 4) = amort res(k, 5) = crd - amort ' CRD en fin de période crd = crd - amort Next k With ThisWorkbook.Sheets("RES_Echeancier") .Range("A2:E1048576").ClearContents ' zone jetable, on repart propre .Range("A2").Resize(nMois, 5).Value = res ' une seule écriture End With ' contrôle : le CRD final doit être nul à l'arrondi près If Abs(crd) > 0.01 Then MsgBox "Contrôle CRD final : " & Format(crd, "0.00"), vbExclamation End Sub

Simulation Monte-Carlo : charge annuelle d'un portefeuille

Option Explicit Sub MonteCarloCharge() Const NSIM As Long = 100000 Dim lambda As Double, mu As Double, sigma As Double, graine As Long With ThisWorkbook lambda = .Names("Hyp_FrequenceMoy").RefersToRange.Value ' sinistres / an mu = .Names("Hyp_LogMu").RefersToRange.Value ' params de la lognormale sigma = .Names("Hyp_LogSigma").RefersToRange.Value graine = .Names("Hyp_Graine").RefersToRange.Value End With ' Reproductibilité : Rnd -1 réinitialise, Randomize fixe la graine. ' Sans ces deux lignes, deux exécutions donnent deux résultats : indéfendable. Rnd -1 Randomize graine Dim res() As Double: ReDim res(1 To NSIM) Dim s As Long, k As Long, nSin As Long, total As Double Application.ScreenUpdating = False For s = 1 To NSIM nSin = TiragePoisson(lambda) total = 0 For k = 1 To nSin total = total + Exp(mu + sigma * InverseNormaleCentree(Rnd)) Next k res(s) = total Next s With Application.WorksheetFunction ThisWorkbook.Names("Res_Moyenne").RefersToRange.Value = .Average(res) ThisWorkbook.Names("Res_Q995").RefersToRange.Value = .Percentile_Inc(res, 0.995) End With Application.ScreenUpdating = True End Sub ' Tirage de Poisson — algorithme de Knuth, correct pour lambda modéré Private Function TiragePoisson(lambda As Double) As Long Dim L As Double, p As Double, k As Long L = Exp(-lambda): p = 1: k = 0 Do k = k + 1 p = p * Rnd Loop While p > L TiragePoisson = k - 1 End Function ' Quantile de la loi normale centrée réduite, via la fonction d'Excel Private Function InverseNormaleCentree(u As Double) As Double If u <= 0 Then u = 0.0000001 If u >= 1 Then u = 0.9999999 InverseNormaleCentree = Application.WorksheetFunction.Norm_S_Inv(u) End Function

Trois pièges de simulation

La graine. Sans graine fixée et journalisée, le résultat n'est pas reproductible — c'est le premier point que relèvera une revue. Le nombre de simulations. Un quantile à 99,5 % estimé sur 10 000 tirages est très instable ; relancez avec deux graines différentes et comparez avant de choisir votre NSIM. L'indépendance. Le modèle ci-dessus suppose les sinistres indépendants entre eux : c'est faux pour un événement climatique, qui touche tout le portefeuille d'un coup.

Erreurs, journal, et ce que le contrôle viendra lire

Sub CalculerProvisions() Dim t0 As Double: t0 = Timer On Error GoTo Echec Application.ScreenUpdating = False Application.Calculation = xlCalculationManual ProjeterUltimes ' le traitement lui-même Journaliser "Provisions", "OK", Timer - t0, "" Fin: ' remise en état, qu'il y ait eu erreur ou non — c'est le point critique Application.Calculation = xlCalculationAutomatic Application.ScreenUpdating = True Exit Sub Echec: Journaliser "Provisions", "ERREUR", Timer - t0, Err.Number & " — " & Err.Description MsgBox "Le calcul a échoué et rien n'a été publié." & vbCrLf & _ Err.Description, vbCritical Resume Fin End Sub Private Sub Journaliser(tache As String, statut As String, _ duree As Double, message As String) Dim ws As Worksheet: Set ws = ThisWorkbook.Sheets("JOURNAL") Dim r As Long: r = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row + 1 ws.Cells(r, 1).Value = Now ' quand ws.Cells(r, 2).Value = Environ("USERNAME") ' qui ws.Cells(r, 3).Value = tache ' quoi ws.Cells(r, 4).Value = statut ws.Cells(r, 5).Value = Round(duree, 2) ws.Cells(r, 6).Value = message ws.Cells(r, 7).Value = ThisWorkbook.Name ws.Cells(r, 8).Value = ThisWorkbook.Names("Hyp_Version").RefersToRange.Value ws.Cells(r, 9).Value = ThisWorkbook.Names("Hyp_Graine").RefersToRange.Value End Sub

Checklist avant de laisser un outil partir en production

  • Option Explicit en tête de chaque module, et le classeur compile (Débogage → Compiler VBAProject) sans erreur.
  • Aucune valeur en dur dans le code : taux, chargements, chemins, seuils sont tous sur la feuille Hypothèses, nommés.
  • Aucune adresse de cellule en dur : uniquement des noms définis.
  • Un jeu de test dont le résultat attendu est connu, et qu'on rejoue après chaque modification.
  • Le journal alimenté en ajout seul, avec version et graine.
  • La zone de résultats entièrement réécrite à chaque exécution : jamais de résidu d'un calcul précédent.
  • Les interrupteurs remis dans le gestionnaire d'erreur — sinon un plantage laisse Excel en calcul manuel, et tous les chiffres suivants sont faux sans prévenir.
  • Une copie du code hors du classeur (export des modules en .bas, versionnés) : un .xlsm corrompu emporte le code avec lui.
  • Le classeur inventorié dans le registre des outils utilisateurs, avec un propriétaire nommé.
