Module 2 · 60 min · départ de zéro

Saisir, corriger, présenter

Excel distingue trois types de contenu, et tout le reste en découle. Comprendre cette distinction dès le début vous épargnera les trois quarts des problèmes que rencontrent les débutants.

2.1

Les trois types de contenu

Quand vous tapez quelque chose, Excel décide tout seul de quoi il s'agit — et vous le montre par l'alignement. C'est votre premier outil de diagnostic, gratuit et permanent.

Comment réparer un nombre devenu texte

Le plus souvent, un triangle vert apparaît dans le coin de la cellule : cliquez dessus → Convertir en nombre. Sinon, sélectionnez la colonne et faites Données → Convertir → Terminer. La cause habituelle : un espace invisible, ou une virgule là où Excel attend un point — ou l'inverse, selon vos paramètres régionaux.

2.2

La poignée de recopie

Le petit carré en bas à droite de la sélection. C'est probablement la fonctionnalité la plus rentable d'Excel pour un débutant.

2.3

Format d'affichage contre valeur réelle

Voici la distinction qui piège absolument tout le monde au début, et qui revient au module 13 sous forme d'écarts d'un centime.

Le principe

Une cellule a une valeur (ce qu'Excel stocke et calcule) et un format (ce que vous voyez). Le format ne change jamais la valeur. Si vous affichez 3,7 avec zéro décimale, vous voyez 4 — mais Excel continue de calculer avec 3,7.

Piège : les dièses #####

Ce n'est pas une erreur. C'est Excel qui vous dit que la colonne est trop étroite pour afficher le nombre en entier. Élargissez-la et tout revient. Il refuse d'afficher un nombre tronqué, parce qu'un chiffre coupé serait mensonger — contrairement au texte, qu'il accepte de rogner.

Piège : la fusion de cellules

« Fusionner et centrer » paraît pratique et casse le tri, le filtre, le copier-coller et les tableaux croisés dynamiques. Utilisez Centrer sur plusieurs colonnes (dans Ctrl 1 → Alignement) : le rendu est identique, sans aucun des inconvénients.

Module 3 · 70 min · départ de zéro

Vos premières formules

Une formule commence toujours par =. C'est la seule règle absolue d'Excel. Tout le reste s'apprend par empilement, et ce module pose les fondations sur lesquelles reposeront les onze suivants.

3.1

Anatomie d'une formule

Pourquoi écrire =B2*C2 plutôt que =12*39

Parce qu'une formule qui pointe des cellules se met à jour toute seule. Changez la quantité en B2, le total suit. Un nombre tapé en dur dans une formule est une bombe à retardement : personne ne le verra, et il restera faux pour toujours. C'est le principe qui fonde tout le reste du cours.

3.2

Les cinq fonctions à connaître en premier

=SOMME(B2:B9) // additionne =MOYENNE(B2:B9) // la moyenne, en ignorant les cellules vides =MIN(B2:B9) // la plus petite valeur =MAX(B2:B9) // la plus grande =NB(B2:B9) // combien de NOMBRES — pas de textes =NBVAL(B2:B9) // combien de cellules NON VIDES, texte compris

Astuce : la somme automatique

Placez-vous sous une colonne de nombres et faites Alt+= : Excel devine la plage et écrit la formule. Vérifiez quand même ce qu'il a sélectionné — il se trompe dès qu'il y a une ligne vide.

Piège : NB contre NBVAL

NB ne compte que les nombres. Sur une colonne de noms de clients, il renvoie 0, et beaucoup de débutants en concluent que leur fichier est vide. Pour compter des lignes remplies quelles qu'elles soient, c'est NBVAL.

3.3

Le dollar : références relatives et absolues

C'est le concept qui bloque le plus de débutants, et il s'explique en une phrase : quand on recopie une formule, les références se décalent. Le symbole $ sert à en empêcher une de bouger.

3.4

Le premier test logique : SI

Une formule qui décide. C'est la porte d'entrée vers tout ce que fait un tableau de bord.

=SI( condition ; valeur_si_vrai ; valeur_si_faux ) // concrètement =SI(B2>=1000 ; "Objectif atteint" ; "En retard") =SI(B2>=1000 ; B2*0,05 ; 0) // une prime de 5 % au-delà de 1000 // les opérateurs de comparaison = égal <> différent > supérieur >= supérieur ou égal < inférieur <= inférieur ou égal

Piège : les guillemets

Tout texte écrit dans une formule doit être entre guillemets droits : "En retard". Sans eux, Excel cherche une plage nommée portant ce nom, ne la trouve pas et renvoie #NOM?. Les nombres, eux, ne prennent jamais de guillemets — "1000" serait du texte, et la comparaison deviendrait fausse.

Module 4 · 90 min

Des données que le dashboard peut digérer

80 % des dashboards ratés se jouent ici. Un tableau croisé dynamique ne rattrape jamais une base mal structurée — il la recopie en plus joli.

4.1

Une ligne = un fait, une colonne = une variable

Le format que les humains lisent bien (mois en colonnes) est exactement celui qu'Excel exploite mal. Il faut une base « à plat » : chaque ligne raconte un événement complet.

4.2

Le tableau structuré, votre meilleur allié

Sélectionnez une cellule de votre base, faites Ctrl+L (Ctrl T en anglais), puis renommez-le immédiatement dans Création de tableau → Nom du tableau. Ce nom devient une adresse vivante.

Piège

Un tableau structuré n'accepte pas les cellules fusionnées, les lignes vides au milieu, ni deux en-têtes identiques. Excel renomme silencieusement en Produit2 — et votre formule pointe alors sur la mauvaise colonne.

4.3

Nettoyer avec Power Query

Power Query (Données → Obtenir des données) enregistre vos manipulations comme une recette. Le mois prochain, nouveau fichier, même recette, un clic sur Actualiser tout.

Les six transformations qui servent tout le temps

  • Type de données — forcez Date, Nombre décimal, Texte dès la deuxième étape. 90 % des bugs de TCD viennent d'une date restée en texte.
  • Dépivoter les colonnes — transforme un rapport en base (figure 3).
  • Fractionner une colonne — par délimiteur, par nombre de caractères.
  • Colonne à partir d'exemples — vous tapez deux résultats attendus, Power Query devine la règle.
  • Fusionner des requêtes — l'équivalent d'un RECHERCHEX, mais côté données, une fois pour toutes.
  • Ajouter des requêtes — empile 12 fichiers mensuels en une seule table.

Astuce : charger depuis un dossier

Données → Obtenir des données → À partir d'un fichier → À partir d'un dossier. Chaque nouveau CSV déposé dans le dossier est absorbé au prochain Actualiser tout. C'est le dispositif le plus rentable de toute la formation.

4.4

Les cinq saletés à traquer

Cellules fusionnées

Elles cassent le tri, le filtre, le TCD. Remplacez par Centrer sur plusieurs colonnes dans Ctrl 1 → Alignement.

Totaux au milieu de la base

Un TCD les comptera comme des lignes. Les totaux se calculent, ils ne se stockent pas.

Nombres stockés en texte

Alignés à gauche, ignorés par SOMME. Correction rapide : coller-spécial Ajouter une cellule vide, ou Convertir dans Power Query.

Espaces invisibles

« Ouest » ≠ « Ouest ». =SUPPRESPACE(A2), ou Format → Supprimer les espaces dans Power Query.

Dates en texte

Test imparable : =ESTNUM(A2). Si c'est FAUX, aucun groupement par mois ne fonctionnera jamais.

Lignes en double

Données → Supprimer les doublons — mais toujours sur une copie, et seulement après avoir vérifié quelles colonnes définissent l'unicité.

Module 5 · 100 min

Les formules qui portent un dashboard

Excel compte plus de 500 fonctions. Une trentaine suffit à tout faire, à condition de savoir laquelle sert à quoi. Ce module les passe en revue par usage — lire une formule, traiter du texte, des dates, décider, agréger, chercher — avec le piège de chacune.

5.1

Comment Excel lit une formule

Avant d'empiler les fonctions, il faut savoir dans quel ordre Excel calcule. Une parenthèse mal placée ne produit pas d'erreur : elle produit un résultat faux, ce qui est bien pire.

Nommer une cellule pour la rendre lisible

Sélectionnez une cellule, tapez un nom dans la zone Nom, validez. =Prix*TauxTVA se relit dix fois plus vite que =B4*$H$2, et le nom ne se décale jamais à la recopie — il joue le rôle d'un $ permanent. Ctrl F3 ouvre le gestionnaire, F3 colle un nom dans une formule.

Imbriquer sans se perdre

Une fonction peut servir d'argument à une autre : =ARRONDI(MOYENNE(B2:B9);2). Excel calcule toujours de l'intérieur vers l'extérieur. Pour vérifier une imbrication, sélectionnez la partie interne dans la barre de formule et appuyez sur F9 : vous voyez sa valeur avant de continuer.

5.2

Le texte : découper, nettoyer, recomposer

Les données arrivent rarement dans le bon format. Une colonne « Nom Prénom », un code produit collé à sa référence, des espaces en trop : ces fonctions réparent tout cela.

// nettoyer =SUPPRESPACE(A2) // enlève les espaces en trop, garde ceux du milieu =EPURAGE(A2) // enlève les caractères non imprimables d'un export =SUBSTITUE(A2 ; "." ; ",") // remplace toutes les occurrences // recomposer =A2 & " " & B2 // l'esperluette colle deux textes =CONCAT(A2:D2) // colle toute une plage =JOINDRE.TEXTE(" - " ; VRAI ; A2:D2) // avec séparateur, en ignorant les vides // transformer =MAJUSCULE(A2) =MINUSCULE(A2) =NOMPROPRE(A2) =NBCAR(A2) // combien de caractères =TEXTE(A2 ; "jj/mm/aaaa") // forcer un affichage DANS du texte =CNUM(A2) // texte qui ressemble à un nombre → vrai nombre

Piège : le faux doublon

"Dupont " et "Dupont" sont deux valeurs différentes pour Excel — et pour un TCD, deux lignes distinctes. Avant toute analyse, passez vos colonnes de texte à SUPPRESPACE. C'est la cause numéro un des totaux qui ne tombent pas juste.

5.3

Les dates : compter, décaler, extraire

Rappel du module 2 : une date est un nombre. C'est ce qui permet tous les calculs qui suivent.

// extraire un morceau =ANNEE(A2) =MOIS(A2) =JOUR(A2) =JOURSEM(A2 ; 2) // 1 = lundi … 7 = dimanche avec le type 2 =NO.SEMAINE(A2 ; 21) // numéro de semaine ISO, celui des entreprises =TEXTE(A2 ; "mmmm") // le mois en toutes lettres, en TEXTE // reconstruire =DATE(2026 ; 3 ; 12) =MOIS.DECALER(A2 ; 3) // +3 mois, sans casser les fins de mois =SERIE.JOUR.OUVRE(A2 ; 10 ; Feries) // 10 jours ouvrés plus tard

Piège : trier par mois en toutes lettres

=TEXTE(A2;"mmmm") produit du texte. Un tri classera alors « avril » avant « janvier », par ordre alphabétique. Pour un dashboard, gardez une colonne date réelle pour le tri et n'utilisez le libellé que pour l'affichage — ou laissez le TCD grouper les dates lui-même.

5.4

La logique : décider, combiner, rattraper

// combiner plusieurs conditions =SI(ET(B2>=1000 ; C2="Pro") ; "Prioritaire" ; "Standard") =SI(OU(B2>5000 ; C2="VIP") ; "Suivi rapproché" ; "") // plusieurs cas : lisible, au lieu de SI imbriqués en cascade =SI.CONDITIONS( B2>=10000 ; "A" ; B2>=5000 ; "B" ; B2>=1000 ; "C" ; VRAI ; "D" ) // VRAI joue le rôle du "sinon" // une valeur parmi une liste =SI.MULTIPLE( C2 ; "Nord";1 ; "Sud";2 ; "Est";3 ; 0 ) // neutraliser une erreur =SIERREUR( B2/C2 ; 0 ) // attrape TOUTES les erreurs =SI.NON.DISP( RECHERCHEX(...) ; "Inconnu" ) // n'attrape que #N/A

Piège : SIERREUR qui cache la poussière

SIERREUR masque toutes les erreurs, y compris celles qui signalent un vrai problème — une faute de frappe, une plage décalée. Sur un dashboard, préférez SI.NON.DISP quand vous ne voulez neutraliser qu'une recherche infructueuse : les autres erreurs continueront de vous alerter, et c'est ce que vous voulez.

L'ordre compte dans SI.CONDITIONS

Les conditions sont évaluées de haut en bas, et la première vraie l'emporte. Si vous mettez B2>=1000 en premier, tout le monde sera classé « C ». Allez toujours du plus restrictif au plus large.

5.5

Maths, statistiques et arrondis

// arrondir — voir le module 13 pour les conséquences comptables =ARRONDI(A2;2) =ARRONDI.SUP(A2;0) =ARRONDI.INF(A2;0) =ARRONDI.AU.MULTIPLE(A2;50) // au palier de 50 le plus proche =ENT(A2) =MOD(A2;7) =ABS(A2) // la fonction la plus sous-estimée d'Excel =SOMMEPROD(Qte ; Prix) // multiplie ligne à ligne PUIS additionne =SOMMEPROD((Region="Ouest")*(Gamme="Pro")*CA) // somme conditionnelle // classements et distribution =RANG(B2 ; Ventes ; 0) // 0 = décroissant =GRANDE.VALEUR(Ventes ; 3) // la 3e plus grande =PETITE.VALEUR(Ventes ; 1) =MEDIANE(Ventes) // souvent plus juste que la moyenne =ECARTYPE.PEARSON(Ventes) // la dispersion =CENTILE.INCLURE(Ventes ; 0,9) // le seuil des 10 % du haut

Moyenne ou médiane ?

Sur des paniers d'achat, un seul client à 80 000 € tire la moyenne vers le haut et donne une image fausse du client typique. La médiane — la valeur qui coupe la population en deux — résiste à ces valeurs extrêmes. Affichez les deux côte à côte : leur écart est en soi une information sur la concentration de votre activité.

Pourquoi apprendre SOMMEPROD

Elle fait en une formule ce qui demanderait une colonne intermédiaire : un chiffre d'affaires total sans colonne « Total » par ligne. Et les conditions écrites en multiplication de tests — (A=1)*(B=2) — fonctionnent dans toutes les versions d'Excel, là où SOMME.SI.ENS ne gère pas certains cas comme les critères sur résultat de formule.

5.6

RECHERCHEX : la fin de RECHERCHEV

// dans la table Ventes, ramener la gamme du produit =RECHERCHEX([@Code] ; Produits[Code] ; Produits[Gamme] ; "Inconnu") // avant 2021, l'équivalent robuste =INDEX(Produits[Gamme] ; EQUIV([@Code] ; Produits[Code] ; 0))

Piège

Le 4e argument est facultatif — mais si vous l'omettez, une correspondance manquante renvoie #N/A, et un seul #N/A contamine toute la colonne de votre TCD. Mettez toujours une valeur de repli explicite : "Inconnu" ou 0, jamais "" dans une colonne numérique.

5.7

SOMME.SI.ENS : agréger sous conditions

=SOMME.SI.ENS(Ventes[CA] ; Ventes[Région] ; $B$2 ; Ventes[Gamme] ; $B$3) // avec une fourchette de dates — noter les guillemets autour de l'opérateur =SOMME.SI.ENS(Ventes[CA] ; Ventes[Date] ; ">="&$D$2 ; Ventes[Date] ; "<="&$D$3) // la même famille : NB.SI.ENS, MOYENNE.SI.ENS, MAX.SI.ENS, MIN.SI.ENS =NB.SI.ENS(Ventes[Client] ; "<>")
5.8

Les formules dynamiques : une formule, plusieurs cellules

Depuis Excel 2021, une formule peut renvoyer un bloc entier de résultats, qui se « déverse » dans les cellules voisines. C'est ce qui permet des listes de filtres ou des tops qui grandissent tout seuls.

=UNIQUE(Ventes[Région]) // la liste des valeurs distinctes =TRIER(UNIQUE(Ventes[Région])) // …triée =FILTRE(Ventes ; Ventes[Région]=$B$1 ; "aucune vente") // un sous-tableau vivant =TRIER(FILTRE(Ventes ; Ventes[CA]>5000) ; 5 ; -1) // trié par la 5e colonne, décroissant =PRENDRE(TRIER(Récap ; 2 ; -1) ; 5) // le top 5

LET : nommer pour ne plus se répéter

Quand la même sous-expression revient trois fois dans une formule, elle est calculée trois fois. LET la nomme et la calcule une seule fois — plus rapide, et surtout relisible dans six mois.

=LET( ca ; SOMME.SI.ENS(Ventes[CA] ; Ventes[Région] ; $B$1) ; obj ; RECHERCHEX($B$1 ; Objectifs[Région] ; Objectifs[Cible] ; 0) ; SI(obj=0 ; "pas d'objectif" ; ca/obj - 1) )

Mesures : les calculs qui suivent le filtre

Une mesure (Power Pivot) se recalcule dans le contexte de chaque cellule du TCD. C'est ce qui permet d'écrire « % de croissance » une seule fois, et de le voir juste par région, par mois, par gamme, et au total.

// Données → Mesures → Nouvelle mesure. Syntaxe DAX, virgule comme séparateur. CA := SUM(Ventes[CA]) Commandes := DISTINCTCOUNT(Ventes[N° commande]) CA N-1 := CALCULATE([CA], SAMEPERIODLASTYEAR(Calendrier[Date])) Croissance % := DIVIDE([CA] - [CA N-1], [CA N-1]) Marge % := DIVIDE([CA] - SUMX(Ventes, Ventes[Qté] * RELATED(Produits[Coût])), [CA])

Mesure

Calculée au moment de l'affichage, dans le contexte du filtre. Ne pèse rien en mémoire. À privilégier pour tout ce qui s'agrège.

recommandé

Colonne calculée

Calculée ligne par ligne, stockée. Nécessaire seulement quand la valeur doit servir de catégorie (ligne, colonne ou segment).

Piège : DIVIDE plutôt que /

[CA]/[CA N-1] renvoie une erreur sur la première année, où N-1 vaut zéro — et l'erreur se propage jusqu'au total. DIVIDE() renvoie un blanc propre à la place.

Les fonctions financières d'Excel raisonnent en flux : ce que vous recevez est positif, ce que vous payez est négatif. D'où le -capital dans VPM. Fixez la convention une fois, écrivez-la sur la feuille d'hypothèses.

16.5

Assurance — triangle de liquidation et Chain-Ladder

Le calcul de provisionnement le plus répandu. On observe des sinistres payés cumulés par année de survenance et année de développement, on en déduit des facteurs de passage, et on prolonge jusqu'à l'ultime.

Option Explicit ' Facteurs de développement pondérés, sur un triangle cumulé carré. ' triangle : plage n x n, cellules non observées vides. Function FacteursChainLadder(triangle As Range) As Variant Dim t As Variant: t = triangle.Value Dim n As Long: n = UBound(t, 1) Dim f() As Double: ReDim f(1 To n - 1) Dim i As Long, j As Long, num As Double, den As Double For j = 1 To n - 1 num = 0: den = 0 ' seules les lignes observées en j ET en j+1 entrent au dénominateur For i = 1 To n - j den = den + t(i, j) num = num + t(i, j + 1) Next i If den <> 0 Then f(j) = num / den Else f(j) = 1 Next j FacteursChainLadder = f End Function ' Complète le triangle et renvoie ultime et provision par année de survenance. Sub ProjeterUltimes() Dim rg As Range: Set rg = ThisWorkbook.Names("Dat_Triangle").RefersToRange Dim t As Variant: t = rg.Value Dim n As Long: n = UBound(t, 1) Dim f As Variant: f = FacteursChainLadder(rg) Dim res() As Double: ReDim res(1 To n, 1 To 2) Dim i As Long, j As Long, dernier As Long, ult As Double For i = 1 To n dernier = n - i + 1 ' dernière colonne observée de la ligne i ult = t(i, dernier) For j = dernier To n - 1 ult = ult * f(j) Next j res(i, 1) = ult ' ultime res(i, 2) = ult - t(i, dernier) ' provision restant à payer Next i ThisWorkbook.Names("Res_Ultimes").RefersToRange.Resize(n, 2).Value = res End Sub

Piège

Le triangle doit être cumulé. Appliquer Chain-Ladder à des paiements non cumulés donne des facteurs qui n'ont aucun sens — et le résultat reste plausible à l'œil, ce qui le rend dangereux. Ajoutez un contrôle : chaque ligne doit être croissante.

Assurance — tarification vie sur table de mortalité

Une fonction personnalisée (UDF) utilisable directement dans une cellule : prime unique d'un capital décès temporaire, actualisée, à partir d'une table de survivants l(x).

' lxTable : une colonne de survivants, ligne 1 = âge 0, ligne 2 = âge 1, etc. ' x : âge à la souscription · n : durée en années · i : taux technique annuel Function PrimeUniqueDeces(lxTable As Range, x As Long, _ n As Long, capital As Double, i As Double) As Double Dim lx As Variant: lx = lxTable.Value Dim v As Double: v = 1 / (1 + i) ' facteur d'actualisation Dim k As Long, a As Double, lStart As Double lStart = lx(x + 1, 1) ' survivants à l'âge x If lStart <= 0 Then PrimeUniqueDeces = CVErr(xlErrValue): Exit Function For k = 0 To n - 1 ' décès entre x+k et x+k+1, actualisés en fin d'année a = a + v ^ (k + 1) * (lx(x + k + 1, 1) - lx(x + k + 2, 1)) / lStart Next k PrimeUniqueDeces = capital * a ' prime pure, hors chargements End Function

Dans la cellule

=PrimeUniqueDeces(Hyp_Lx ; 45 ; 10 ; 100000 ; 0,02) — la fonction se comporte comme n'importe quelle fonction Excel, et se recalcule avec les hypothèses.

Ce qu'il reste à ajouter

Chargements d'acquisition et de gestion, frais sur prime, éventuelle sélection médicale, périodicité de paiement. La prime pure n'est jamais la prime commerciale.

Sub GenererEcheancier() Dim capital As Double, tauxAnnuel As Double, nMois As Long With ThisWorkbook capital = .Names("Hyp_Capital").RefersToRange.Value tauxAnnuel = .Names("Hyp_Taux").RefersToRange.Value nMois = .Names("Hyp_DureeMois").RefersToRange.Value End With Dim i As Double: i = tauxAnnuel / 12 Dim mens As Double If i = 0 Then mens = capital / nMois Else mens = capital * i / (1 - (1 + i) ^ -nMois) ' annuité constante End If Dim res() As Double: ReDim res(1 To nMois, 1 To 5) Dim k As Long, crd As Double, interets As Double, amort As Double crd = capital For k = 1 To nMois interets = crd * i amort = mens - interets res(k, 1) = k res(k, 2) = crd ' capital restant dû en début de période res(k, 3) = interets res(k, 4) = amort res(k, 5) = crd - amort ' CRD en fin de période crd = crd - amort Next k With ThisWorkbook.Sheets("RES_Echeancier") .Range("A2:E1048576").ClearContents ' zone jetable, on repart propre .Range("A2").Resize(nMois, 5).Value = res ' une seule écriture End With ' contrôle : le CRD final doit être nul à l'arrondi près If Abs(crd) > 0.01 Then MsgBox "Contrôle CRD final : " & Format(crd, "0.00"), vbExclamation End Sub

Simulation Monte-Carlo : charge annuelle d'un portefeuille

Option Explicit Sub MonteCarloCharge() Const NSIM As Long = 100000 Dim lambda As Double, mu As Double, sigma As Double, graine As Long With ThisWorkbook lambda = .Names("Hyp_FrequenceMoy").RefersToRange.Value ' sinistres / an mu = .Names("Hyp_LogMu").RefersToRange.Value ' params de la lognormale sigma = .Names("Hyp_LogSigma").RefersToRange.Value graine = .Names("Hyp_Graine").RefersToRange.Value End With ' Reproductibilité : Rnd -1 réinitialise, Randomize fixe la graine. ' Sans ces deux lignes, deux exécutions donnent deux résultats : indéfendable. Rnd -1 Randomize graine Dim res() As Double: ReDim res(1 To NSIM) Dim s As Long, k As Long, nSin As Long, total As Double Application.ScreenUpdating = False For s = 1 To NSIM nSin = TiragePoisson(lambda) total = 0 For k = 1 To nSin total = total + Exp(mu + sigma * InverseNormaleCentree(Rnd)) Next k res(s) = total Next s With Application.WorksheetFunction ThisWorkbook.Names("Res_Moyenne").RefersToRange.Value = .Average(res) ThisWorkbook.Names("Res_Q995").RefersToRange.Value = .Percentile_Inc(res, 0.995) End With Application.ScreenUpdating = True End Sub ' Tirage de Poisson — algorithme de Knuth, correct pour lambda modéré Private Function TiragePoisson(lambda As Double) As Long Dim L As Double, p As Double, k As Long L = Exp(-lambda): p = 1: k = 0 Do k = k + 1 p = p * Rnd Loop While p > L TiragePoisson = k - 1 End Function ' Quantile de la loi normale centrée réduite, via la fonction d'Excel Private Function InverseNormaleCentree(u As Double) As Double If u <= 0 Then u = 0.0000001 If u >= 1 Then u = 0.9999999 InverseNormaleCentree = Application.WorksheetFunction.Norm_S_Inv(u) End Function

Trois pièges de simulation

La graine. Sans graine fixée et journalisée, le résultat n'est pas reproductible — c'est le premier point que relèvera une revue. Le nombre de simulations. Un quantile à 99,5 % estimé sur 10 000 tirages est très instable ; relancez avec deux graines différentes et comparez avant de choisir votre NSIM. L'indépendance. Le modèle ci-dessus suppose les sinistres indépendants entre eux : c'est faux pour un événement climatique, qui touche tout le portefeuille d'un coup.

Erreurs, journal, et ce que le contrôle viendra lire

Sub CalculerProvisions() Dim t0 As Double: t0 = Timer On Error GoTo Echec Application.ScreenUpdating = False Application.Calculation = xlCalculationManual ProjeterUltimes ' le traitement lui-même Journaliser "Provisions", "OK", Timer - t0, "" Fin: ' remise en état, qu'il y ait eu erreur ou non — c'est le point critique Application.Calculation = xlCalculationAutomatic Application.ScreenUpdating = True Exit Sub Echec: Journaliser "Provisions", "ERREUR", Timer - t0, Err.Number & " — " & Err.Description MsgBox "Le calcul a échoué et rien n'a été publié." & vbCrLf & _ Err.Description, vbCritical Resume Fin End Sub Private Sub Journaliser(tache As String, statut As String, _ duree As Double, message As String) Dim ws As Worksheet: Set ws = ThisWorkbook.Sheets("JOURNAL") Dim r As Long: r = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row + 1 ws.Cells(r, 1).Value = Now ' quand ws.Cells(r, 2).Value = Environ("USERNAME") ' qui ws.Cells(r, 3).Value = tache ' quoi ws.Cells(r, 4).Value = statut ws.Cells(r, 5).Value = Round(duree, 2) ws.Cells(r, 6).Value = message ws.Cells(r, 7).Value = ThisWorkbook.Name ws.Cells(r, 8).Value = ThisWorkbook.Names("Hyp_Version").RefersToRange.Value ws.Cells(r, 9).Value = ThisWorkbook.Names("Hyp_Graine").RefersToRange.Value End Sub

Checklist avant de laisser un outil partir en production

  • Option Explicit en tête de chaque module, et le classeur compile (Débogage → Compiler VBAProject) sans erreur.
  • Aucune valeur en dur dans le code : taux, chargements, chemins, seuils sont tous sur la feuille Hypothèses, nommés.
  • Aucune adresse de cellule en dur : uniquement des noms définis.
  • Un jeu de test dont le résultat attendu est connu, et qu'on rejoue après chaque modification.
  • Le journal alimenté en ajout seul, avec version et graine.
  • La zone de résultats entièrement réécrite à chaque exécution : jamais de résidu d'un calcul précédent.
  • Les interrupteurs remis dans le gestionnaire d'erreur — sinon un plantage laisse Excel en calcul manuel, et tous les chiffres suivants sont faux sans prévenir.
  • Une copie du code hors du classeur (export des modules en .bas, versionnés) : un .xlsm corrompu emporte le code avec lui.
  • Le classeur inventorié dans le registre des outils utilisateurs, avec un propriétaire nommé.
